## Quick Signals (no tools needed)

| Signal | Human writing | AI writing |
|---|---|---|
| Sentence length variance | High (mixed) | Low (uniform rhythm) |
| Perplexity (surprise) | Spiky, uneven | Smooth, predictable |
| Burstiness | Short/long alternation | Steady cadence |
| Personal anecdotes | Specific, odd details | Generic, hedged |
| Hedging phrases | Occasional | Heavy ("it's important to note", "delve") |
| Repetition | Thematic | Structural (same paragraph shape) |
| Factual specificity | Dated, cited, verifiable | Vague, plausible-sounding |

**Red-flag phrases** (weak alone, strong in clusters):
"delve into", "in today's fast-paced world", "it's important to note", "furthermore", "in conclusion", "tapestry", "landscape of", "navigate the complexities", "leverage", "robust", "seamless".

## Heuristic Check (quick script)

```python
import re, statistics

def ai_signals(text: str) -> dict:
    sents = [s for s in re.split(r'(?<=[.!?])\s+', text) if len(s.split()) > 3]
    lens = [len(s.split()) for s in sents]
    if len(lens) < 5:
        return {"error": "too short to judge"}
    cv = statistics.pstdev(lens) / (statistics.mean(lens) or 1)  # coefficient of variation
    cliches = len(re.findall(r"delve|tapestry|fast-paced|important to note|furthermore|moreover|leverage|robust|seamless|landscape", text, re.I))
    return {
        "sentences": len(sents),
        "len_cv": round(cv, 2),          # human often > 0.45; AI often < 0.35
        "cliche_hits": cliches,
        "likely_ai": cv < 0.35 and cliches >= 2,
    }
```

Low `len_cv` + high cliche density is the classic LLM fingerprint.

## Using a Detector API

curl -X POST "https://api.copyleaks.com/v2/writer-detector/check"   -H "Authorization: Bearer $COPYLEAKS_TOKEN"   -H "Content-Type: application/json"   -d '{"text": "…the text to check…"}'

Read `aiScore` (0–100) and `isHuman`. Combine with the heuristic above — **no single detector is reliable alone** (false positives on non-native English, translated text, and formulaic technical writing).

## Workflow

1. Run the heuristic script for a fast, offline signal
2. If borderline, run 2 different detectors (e.g. Copyleaks + GPTZero-style)
3. Compare scores — **agreement across tools** is stronger than any one number
4. For high-stakes calls (academic integrity), look for **process evidence** (drafts, revisions, sources) not just a score

## Limits & Ethics

- **No detector is 100% accurate** — treat output as a signal, not proof
- Non-native English writers get higher false-positive rates
- AI-assisted editing (Grammarly, translation) can trip detectors
- Always give the author a chance to respond before acting on a score
